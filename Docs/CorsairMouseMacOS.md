# Corsair Mouse Setup on macOS

A Corsair mouse using iCUE requires both of the following macOS permissions to work correctly.

## 1. Enable Input Monitoring

1. Open **System Settings**.
2. Go to **Privacy & Security** > **Input Monitoring**.
3. Enable **iCUE.app**.

## 2. Enable the Driver Extension

1. Open **System Settings**.
2. Go to **General** > **Login Items & Extensions**.
3. Scroll all the way to the bottom and open **Driver Extensions**.
4. Enable **iCUE Virtual Device.app**.

Both settings are required. If the mouse still does not work after enabling them, restart iCUE or restart the Mac so the permissions and driver extension are reloaded.
